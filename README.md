# DAS Client Previews

Static preview portal for The Dr. Ardis Show client deliverables.

Hosted via GitHub Pages at: `https://atticuseby.github.io/das-client-previews/`

## Adding a preview

1. Drop the HTML file into `previews/`.
2. Add a card to `index.html` following the existing card pattern.
3. Commit and push — Pages deploys automatically.

## GitHub Pages setup (first deploy)

Repo → Settings → Pages → Source: Deploy from branch → `main` / `(root)`.
